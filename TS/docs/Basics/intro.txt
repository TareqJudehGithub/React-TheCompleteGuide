TypeScript (TS)
 
  What is TypeScript?
   - TypeScript is a programming language and a superset of JavaScript that adds 
     optional static typing (static checking).
   - TS is developed by Microsoft (MS) that is based on JS.
   - TS is a static type system.
   - Static checking is the process of detecting errors in our code before run-time.
   - TS Only exists in Development. TS is compiled to JS.
   
   - Using TS benefits:
    - by introducing a static type system that helps developers catch errors early,
      improve code quality, and maintain large-scale applications more efficiently.    

    - Type Safety: It defines what kind of data a variable or function can contain, 
      preventing invalid operations like adding numbers to strings 
    - Analyzes our code as we type.

    - Enhanced IDE Support and Developer Experience:
      - IntelliSense & Autocomplete: Modern IDEs (like VS Code) use TypeScript to 
        provide accurate autocompletion, code navigation, and real-time error feedback. 
      - Safer Refactoring: Because TypeScript understands the structure of the code, 
        renaming variables or changing function signatures across a large project can be 
        done confidently without breaking code in other files. 

    - Better Maintainability and Readability:
      - Self-Documenting Code: Explicit type definitions and interfaces make the code 
        easier to understand, serving as built-in documentation for developers.
      - Structural Typing: It helps in modeling complex data structures and managing 
        code in large-scale projects, making it better for teams and long-term projects.  

    - Improved Scalability and Team Collaboration.
      - Easier Onboarding: Clearer, type-annotated code makes it easier for new 
        developers to understand existing codebases.
      - Enforced Consistency: It aids team members in working independently, reducing 
        miscommunications regarding data structures.
    
    - Compatibility and Future-Proofing
      - Gradual Adoption: You can introduce TypeScript incrementally into existing 
        JavaScript projects by renaming files from .js to .ts
      - Modern JavaScript Features: TypeScript supports latest ECMAScript features 
        (ES6, ES7, etc.) and compiles them into compatible older versions of JavaScript.  
      - Ecosystem Trust: Widely adopted by industry leaders (Google, Microsoft, Slack, 
        Airbnb) and supported by major frameworks like Angular and React.
